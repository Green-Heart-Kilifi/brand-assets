# Green Heart Kilifi — brand assets

Public files for anywhere that needs a stable link to the logo or colours.

| Path | What |
|---|---|
| `logos/` | Eight transparent SVG lockups: horizontal and stacked, in Green, Dark Green, Cream and White. Lettering is outlined, so no font is needed. |
| `tokens.css` | The nine brand colours as CSS custom properties, plus a derived teal ramp. |
| `avatars/payments-agent-256.png`, `-512.png` | Square avatar for the GHK Payments Agent (the illustrated butterfly). |

Direct link pattern: `https://raw.githubusercontent.com/Green-Heart-Kilifi/brand-assets/main/<path>`

Fonts are deliberately not here: their licences do not allow public redistribution.
The canonical brand kit is private; this repo holds only what is safe to publish.
